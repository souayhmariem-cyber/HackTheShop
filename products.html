🛡️ Zone Éducative — XSS Stocké

📌 C'est quoi XSS Stocké ?

XSS Stocké (Cross-Site Scripting) est une attaque où un hacker injecte du code JavaScript malveillant dans un formulaire. Ce code est sauvegardé en base de données et s'exécute chez tous les visiteurs qui voient la page.

⚠️ Comment tester ici ?

Ce formulaire de commentaires est volontairement vulnérable. Tape ceci dans le champ commentaire :

<script>alert('XSS Stocké !')</script>

Une alerte va s'afficher — c'est du XSS Stocké en action !

✅ Comment se protéger ?

Toujours échapper les données avant de les afficher en HTML :

// En PHP
echo htmlspecialchars($commentaire);
