🛡️ Zone Éducative — XSS Réfléchi

📌 C'est quoi XSS Réfléchi ?

XSS Réfléchi est une attaque où le code malveillant est injecté via l'URL ou un formulaire de recherche. Contrairement au XSS Stocké, il n'est pas sauvegardé en base de données — il est directement reflété dans la page.

⚠️ Comment tester ici ?

Cette barre de recherche est volontairement vulnérable. Tape ceci dans le champ recherche :

<script>alert('XSS Réfléchi !')</script>

Une alerte va s'afficher — c'est du XSS Réfléchi en action !

🔗 Via l'URL aussi !

Le XSS Réfléchi peut aussi passer par l'URL. Essaie de coller ceci dans la barre du navigateur :

search.html?q=<script>alert('XSS URL')</script>

✅ Comment se protéger ?

Ne jamais afficher directement l'input utilisateur sans le nettoyer :

// En JavaScript (sécurisé)
element.textContent = userInput;

// En PHP (sécurisé)
echo htmlspecialchars($_GET['q']);
