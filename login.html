🛡️ Zone Éducative — SQL Injection

📌 C'est quoi SQL Injection ?

SQL Injection est une attaque qui permet à un hacker d'injecter du code SQL malveillant dans un formulaire pour manipuler la base de données.

⚠️ Comment tester ici ?

Ce formulaire est volontairement vulnérable. Tape ceci dans le champ Email :

' OR '1'='1' --

Et n'importe quoi dans le mot de passe. Tu vas te connecter sans compte valide !

✅ Comment se protéger ?

Utiliser les requêtes préparées en PHP :

$stmt = $pdo->prepare("SELECT * FROM users WHERE email = ?");
$stmt->execute([$email]);
